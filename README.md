# CMJ実施方法 説明アプリ

大阪体育大学スポーツ科学センター 測定評価部門  
実験参加者へのCMJ（Counter Movement Jump）実施方法を、口頭なしで完結させるためのブラウザアプリ。

---

## ファイル構成

```
CMJ_instruction/
├── index.html                     ← 手動進行版（ボタンで次へ）
├── index_loop.html                ← 自動再生・ループ版
├── generate_narration.py          ← VOICEVOX音声生成スクリプト
├── 20260609_031308000_iOS 1.MOV   ← ジャンプデモ動画（左カラムに常時表示）
└── media/
    └── narr_00.wav ～ narr_08.wav  ← VOICEVOXで生成した音声（スライド0〜8）
```

---

## 使い方

### 手動版（index.html）
`index.html` を Chrome で開く。

| 操作 | 方法 |
|------|------|
| 次のスライド | 「次へ」ボタン / `→` / `スペース` |
| 前のスライド | 「戻る」ボタン / `←` |
| 音声ON/OFF | 🔊ボタン / `M` |
| 全画面 | `F` / 右下ボタン |

### 自動ループ版（index_loop.html）
`index_loop.html` を Chrome で開く。音声終了後2秒で自動的に次のスライドへ進み、最後から最初に戻ってループする。

| 操作 | 方法 |
|------|------|
| 一時停止 / 再開 | ⏸ボタン / `P` |
| 手動で次へ | 「次へ」ボタン / `→` / `スペース` |
| 音声ON/OFF | 🔊ボタン / `M` |
| 全画面 | `F` / 右下ボタン |

## 音声（VOICEVOX）

- 声：**四国めたん ノーマル**（VOICEVOX ID = 2）
- 音声ファイル：`media/narr_00.wav` ～ `narr_08.wav`

### 音声の再生成手順

1. VOICEVOX を起動
2. 以下を実行：

```powershell
cd "C:\Users\大阪体育大学スポーツ科学センター\OneDrive - ouhs.ac.jp\User\02. 測定評価\CMJ_instruction"
python generate_narration.py
```

声を変える場合は `generate_narration.py` の `SPEAKER_ID` を変更する。

| ID | 声 |
|----|-----|
| 0 | 四国めたん（あまあま） |
| 2 | 四国めたん（ノーマル）← 現在 |
| 1 | ずんだもん（あまあま） |
| 3 | ずんだもん（ノーマル） |
| 13 | 青山龍星（落ち着いた男声） |

## ナレーション原稿

| スライド | テキスト |
|----------|----------|
| 0 | CMJテストの実施方法を説明します。このテストではちょうやくこうを計測します。 |
| 1 | こちらがジャンプのデモです。お願いしますの合図で、真上にジャンプしてください。動画ではしゃがむ動作からジャンプまでが一連の流れになっています。 |
| 2 | フォースプレートの上に乗ってください。合図があるまでそのままお待ちください。 |
| 3 | ジャンプ中、手は骨盤に当てて固定してください。腕振りは行いません。 |
| 4 | 着地の際は、足首の怪我を防ぐため、親指の付け根、ぼしきゅうを意識して着地してください。 |
| 5 | 着地後は、オッケーですの合図で、フォースプレートの上でリラックスしてください。 |
| 6 | これを3回繰り返します。以上ですの合図が出たらフォースプレートから降りてください。 |
| 7 | 3つの注意点をまとめます。手は骨盤に固定。ぼしきゅうで着地。フォースプレートの外に落ちないこと。 |
| 8 | 説明は以上です。準備ができたら実験者に声をかけてください。 |
